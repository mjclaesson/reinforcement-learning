# Multi-agent order picking in a simulated warehouse

Final project in *Introduction to Reinforcement Learning*, Jönköping University, 2026.
Joakim Möll, Filip Sjögren, Jesper Claesson, Sebastian Andersson.

Two robots pick their own items from shared shelves in a 9×9 grid warehouse, deliver at a shared
drop-off and must not collide. We train independent tabular Q-learning and n-step Q-learning and compare
a selfish and a cooperative reward.

## What is where

| Path | What |
|---|---|
| `project.ipynb` | Everything in the report: environments, training, all experiments, figures. |
| `figures/` | Figures used in the report, generated by the notebook. |
| `demo/` | Streamlit app used in the presentation (replays trained policies, tables, live training). |
| `gridworld.py`, `value_iteration.py`, `main.py` | Assignment 1, the starting point. |

## Setup

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Run the notebook

```
jupyter lab project.ipynb
```

Running every cell takes about 10 minutes for steps 1–7 and another 40 minutes for the
hyperparameter grid search (54 configurations × 3 seeds × 2 reward modes).

## Run the presentation app

```
python demo/train_models.py      # once, about 3 minutes: trains and saves the policies the app replays
streamlit run demo/app.py
```

`demo/warehouse.py` is generated from the notebook with `python demo/extract_from_notebook.py`;
rerun it if the notebook changes.
